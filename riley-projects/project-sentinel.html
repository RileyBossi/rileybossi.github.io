Cloud Security Project

Microsoft Sentinel Lab

A Microsoft Azure security monitoring project that used Microsoft Sentinel, Azure Logic Apps, Log Analytics, Microsoft Entra ID, and KQL to centralize and investigate identity-related security logs.

Microsoft Sentinel Microsoft Azure Entra ID Azure Logic Apps Log Analytics KQL SIEM

Project Summary

Platform Microsoft Sentinel
Data Source Microsoft Entra ID
Automation Azure Logic Apps
Query Language KQL

Project Overview

The purpose of this project was to gain practical experience with Microsoft Sentinel and understand how identity logs can be collected, centralized, and searched within a cloud-based security information and event management platform.

I created a workflow that collected Microsoft Entra ID log information and forwarded it into a Log Analytics workspace. Microsoft Sentinel was connected to the workspace so that the data could be reviewed and investigated using Kusto Query Language.

This project helped demonstrate how organizations and managed service providers can bring security data from separate environments into one central location for monitoring.

Implementation

  • Created and configured a Log Analytics workspace.
  • Enabled Microsoft Sentinel for centralized security monitoring.
  • Configured the necessary identity access and permissions.
  • Built an Azure Logic App to collect and process Entra ID log information.
  • Forwarded the collected records into the Log Analytics workspace.
  • Verified that the records were available for searching.
  • Used KQL to review and summarize the ingested activity.

Project Outcome

The completed lab provided practical experience building a basic cloud security monitoring pipeline. Identity log data could be collected, sent to a central workspace, and reviewed through Microsoft Sentinel and Log Analytics.

The project strengthened my understanding of SIEM architecture, Azure automation, identity monitoring, log ingestion, and the role of KQL in security investigations.
