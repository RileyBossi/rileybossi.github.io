Network Security Project

At-Home Cybersecurity Lab

A virtual security lab built on macOS using VMware Fusion, pfSense, Snort, Kali Linux, Windows virtual machines, and Wireshark for hands-on practice with network segmentation, firewalling, intrusion detection, and traffic analysis.

Project Overview

The purpose of this project was to create a safe virtual environment for practicing defensive security and basic penetration-testing concepts without affecting a production network.

I used VMware Fusion on macOS to run multiple virtual machines, including a pfSense firewall, a Kali Linux system, and Windows endpoints. The virtual machines were placed on separate network segments so traffic could be controlled, monitored, and tested.

The environment allowed me to practice configuring firewall policies, analyzing network traffic, testing communication between systems, and reviewing intrusion detection alerts.

Lab Architecture

Testing System Kali Linux

Used to generate test traffic and perform controlled security testing.

→
Security Gateway pfSense & Snort

Target Systems Windows Virtual Machines

Used as endpoints for testing, monitoring, and defensive analysis.

Environment Components

  • VMware Fusion hosted the virtual lab on a macOS computer.
  • pfSense acted as the virtual firewall and network gateway.
  • Snort provided intrusion detection and alerting capabilities.
  • Kali Linux was used to generate controlled scans and test traffic.
  • Windows virtual machines acted as monitored endpoints.
  • Wireshark was used to capture and inspect network traffic.
  • Separate virtual networks were used to isolate systems and control communication.

Configuration and Testing

  • Created separate virtual network segments for the lab systems.
  • Configured pfSense interfaces, routing, and firewall rules.
  • Restricted and allowed communication between systems based on the purpose of each network segment.
  • Configured Snort to monitor traffic passing through the firewall.
  • Generated controlled traffic from Kali Linux to test connectivity and detection.
  • Captured packets in Wireshark to review protocols, connections, and unexpected activity.
  • Adjusted firewall and intrusion detection settings based on test results.

Project Outcome

The completed lab provided a reusable environment for practicing network security and defensive monitoring. I was able to isolate systems, control traffic through pfSense, monitor activity with Snort, and review packet-level details using Wireshark.

The project strengthened my understanding of how firewalls, network segmentation, intrusion detection, virtualization, and traffic analysis work together within a layered security environment.
