JavaScript Project

Amazon Clone

A frontend e-commerce application built with HTML, CSS, and JavaScript. The project includes product listings, shopping cart functionality, order calculations, and interactive page updates.

JavaScript HTML CSS DOM Manipulation Local Storage Git

Project Overview

I built this project to strengthen my JavaScript skills by recreating the core features of an online shopping website. Product information is displayed dynamically, and users can add items to a cart, update quantities, and view calculated order totals.

The project helped me practice organizing JavaScript across multiple files, working with stored data, and updating page content based on user actions.

Features and Skills

Dynamic Product Pages

Used JavaScript to display product data and update page content dynamically.

Shopping Cart

Added cart controls for item quantities, totals, and product management.

Local Storage

Stored cart information so selections remained available between page loads.

Event Handling

Used click events and other user interactions to control application behavior.
