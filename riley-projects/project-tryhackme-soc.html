TryHackMe SOC Training Path

SOC Operations SIEM Splunk ELK Stack MITRE ATT&CK Malware Analysis Incident Response
Back to Projects

Overview

I completed TryHackMe's SOC Level 1 and SOC Level 2 learning pathways, including their SOC Simulator — a feature that places you inside a simulated security operations center where you triage live alerts, investigate incidents, and write case reports. This was one of the most structured and hands-on cybersecurity training experiences I've done.

The SOC Simulator stood out because it replicated the pressure of real analyst work — alerts keep coming, context matters, and you have to make triage decisions quickly without all the information you'd like to have.

What I Worked On

SOC Level 1 — Foundational Analyst Skills

  • Alert triage workflows, escalation paths, and SOC operating procedures
  • Phishing analysis using tools like PhishTool, any.run, Hybrid Analysis, Talos, and Messageheader
  • Network traffic analysis with Wireshark, Brim, and Snort
  • SIEM log correlation using Splunk and the ELK Stack
  • Endpoint monitoring with Sysmon, Wazuh, and Windows Event Logs
  • Cyber threat intelligence with OpenCTI, YARA, and MISP
  • MITRE ATT&CK framework mapping for threat actor behavior

SOC Level 2 — Advanced Detection & Response

  • Malware analysis fundamentals: PE header inspection, static and dynamic analysis
  • Detection of living-off-the-land (LOTL) techniques and lateral movement
  • Identifying persistence mechanisms from log data
  • Writing structured incident reports with IOCs, timelines, and recommendations

SOC Simulator — Hands-On Alert Triage

  • Monitored live simulated alert queues and prioritized incidents by severity
  • Identified PowerShell execution events, reverse shell connections, and suspicious DNS
  • Investigated a phishing scenario involving a .LNK file masquerading as a PDF that downloaded a PowerShell payload from GitHub and established a reverse shell
  • Produced full case reports documenting the attack chain, IOCs, and mitigations

Key Takeaways

Context over alerts

A single alert means little. Correlating PowerShell execution, authentication anomalies, and DNS requests is what turns noise into a real incident.

Attacker TTPs beat signatures

Mapping behavior to MITRE ATT&CK helps detect novel threats. Signatures catch known malware; TTPs catch attacker intent regardless of the payload.

Phishing is still king

The .LNK phishing investigation showed how a convincingly-named file, a short PowerShell cradle, and a public repo can bypass basic defenses entirely.

Write everything down

The simulator's case report requirement reinforced that documentation isn't optional — it enables escalation, handoff, and post-incident review.

How This Applies to Real Work

Much of what I practiced in these labs directly mirrors what I do day-to-day at my MSP. Investigating phishing emails, analyzing PowerShell commands via RMM, correlating alerts from our MSSP-provided SIEM — all of that maps back to techniques and mindsets I built through this pathway. The SOC Simulator in particular prepared me to stay calm and methodical under alert pressure rather than chasing every event reactively.
