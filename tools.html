DNS Record Query Tool (PowerShell)

A custom PowerShell DNS troubleshooting utility I created to quickly gather DNS records for domains and subdomains in one place. I originally built this tool while working in MSP environments to simplify troubleshooting and verify whether clients correctly configured DNS records such as SPF, DKIM, and DMARC.

Instead of manually querying records one-by-one, this script consolidates standard DNS records, email security records, and optional subdomain lookups into a single organized output. This made it significantly faster to validate mail flow configurations, identify missing records, and troubleshoot DNS-related issues.

What The Tool Does

  • Queries standard DNS records (A, AAAA, MX, NS, TXT, CNAME, SOA)
  • Checks SPF, DMARC, and DKIM records
  • Supports custom subdomain enumeration
  • Supports querying against custom DNS servers
  • Formats results cleanly for troubleshooting and auditing

Why I Built It

I built this script because I frequently needed a fast way to verify whether DNS records had been added correctly during migrations, email security deployments, and troubleshooting scenarios. Having everything consolidated into a single output reduced repetitive manual lookups and improved troubleshooting efficiency.
