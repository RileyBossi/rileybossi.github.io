TryHackMe Junior Penetration Tester

Completed hands-on modules from TryHackMe's Junior Penetration Tester pathway to better understand attacker methodology and translate offensive techniques into stronger defensive controls.

Nmap Burp Suite Metasploit Privilege Escalation MITRE ATT&CK Web Security

Objective

My primary focus is defensive security, but I believe defenders are strongest when they understand how attackers think. The goal of this pathway was not simply to learn offensive tools, but to understand the complete attack lifecycle so I could better identify, investigate, and prevent real-world attacks.

By walking through the same techniques used by threat actors, I gained valuable insight into attacker behavior, common weaknesses in enterprise environments, and the artifacts left behind during exploitation.

Skills & Tools Used

  • Network and service enumeration using Nmap
  • Web application testing with Burp Suite
  • Controlled exploitation using Metasploit
  • Linux privilege escalation techniques
  • Windows privilege escalation techniques
  • Credential abuse and misconfiguration analysis
  • Mapping attacker activity to MITRE ATT&CK
  • Attack chain documentation and reporting

Attack Lifecycle Covered

Reconnaissance

Learned how attackers gather information about target organizations through passive and active discovery techniques.

Enumeration

Used Nmap and service enumeration techniques to identify exposed services, operating systems, and potential attack vectors.

Exploitation

Practiced exploiting intentionally vulnerable systems using Metasploit and web application testing techniques through Burp Suite.

Privilege Escalation

Explored Linux and Windows privilege escalation paths including SUID binaries, weak permissions, service misconfigurations, and credential abuse.

Post-Exploitation

Studied persistence mechanisms, lateral movement concepts, and attacker objectives after gaining initial access.

Hands-On Experience

  • Executed end-to-end attack simulations
  • Identified exposed services and weak configurations
  • Performed web application testing exercises
  • Practiced privilege escalation in Windows and Linux environments
  • Documented attack chains and findings
  • Created defensive recommendations to reduce attack surface
  • Mapped observed activity to MITRE ATT&CK techniques

What I Learned

One of the biggest lessons from this project was that most successful compromises do not require advanced exploits. Weak credentials, excessive privileges, and poor configuration management are often enough for attackers to gain access and move through an environment.

Enumeration is frequently the most important phase of an attack because it uncovers weaknesses defenders can proactively fix. Understanding how attackers discover and prioritize targets has helped me improve my ability to identify risks before they become incidents.

This project also strengthened my understanding of how offensive activity appears from a defender's perspective. Knowing what reconnaissance, exploitation, and privilege escalation look like in logs makes it easier to investigate alerts and distinguish legitimate activity from malicious behavior.
